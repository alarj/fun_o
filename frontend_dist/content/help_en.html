Map view explanation

You see the map on your device as shown below. The map features both markers indicating the track to be covered (checkpoints) and some control buttons.

Meanings of the various symbols and control buttons on the map:

  • The map can be moved and zoomed normally by sliding fingers on the screen or by pinching two fingers together or spreading them apart.

  • Checkpoint (CP) marker. Indicates the location of the CP. Clicking on the marker shows additional information and, if you are in the appropriate location, also a question or activity related to the CP. NB! The smart device's GPS is used for positioning, the accuracy of which can vary. Various GPS interferences are also possible -- GPS does not work indoors and under roofs, and is inaccurate on narrow streets. Therefore, if you think you are at the CP location but the app does not think so, wait a little and move around the vicinity of the CP to give the GPS time to determine the location accurately.

  • Start marker. If a start is marked on the map, it must be completed first. If there is no separate start marker, you can start from any CP marker.

  • Finish marker. After marking the finish, no more CPs can be marked.

  • Orients the map automatically in the direction of north (button is dark) or the north direction of the map is always at the top (button is light). When turning the map while standing still, the smart device's own compass is used (the quality of which is usually poor); while moving, it relies also on GPS data.

  • If the map is oriented according to the compass, the red arrow shows the actual north direction

  • Keeps the map in a mode (ON) where the user is always in the center of the map. The OFF option allows the map to be moved away from the user's location as well. NB! moving the map automatically switches it to the OFF position, otherwise moving would not be possible.

  • If the competition organizer has allowed it, a blue dot shows the user's location on the map. The button described in the previous point always brings this marker to the center of the screen.

  • Opening or closing checkpoint (CP) info windows. Opens or closes all additional info bubbles of the CP markers at the same time

  • Opens a list of different maps available for use. If this button is missing from the options, then only one map can be used.

  • Map selection list. Click on the name to choose a suitable map. Maps can be switched as many times as desired. Sometimes changing the map can be useful because different maps contain different information.

  • Closes the map view

  • Opens this help information

Enjoy using the app!
